# DarkX Official 🤖

A feature-rich WhatsApp Multi-Device Bot built with Baileys library.

## Features ✨

- ✅ Multi-Device Support
- ✅ Auto-Reconnect
- ✅ Anti-Crash System
- ✅ QR Code Login
- ✅ Simple Commands
- ✅ Heroku Ready
- ✅ Termux Compatible

## Commands 🛠️

- `.menu` - Show command menu
- `.ping` - Check bot speed
- `.ai [question]` - Chat with AI
- `.owner` - Contact owner
